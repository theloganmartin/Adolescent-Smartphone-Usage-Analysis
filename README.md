# Adolescent-Smartphone-Usage-Analysis
Project Overview

This project examines behavioral, lifestyle, and demographic factors associated with different levels of daily smartphone use among adolescents.

Research Question

What behavioral, lifestyle, and demographic factors distinguish adolescents with low, moderate, and high levels of daily smartphone use?

Methodology

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature selection and preparation

Multiclass classification using Logistic Regression, Decision Tree, and Random Forest

Model evaluation and comparison

Tools

Python, Pandas, Matplotlib, Seaborn, Scikit-learn, and Jupyter Notebook.

Project Files

Jupyter Notebook: Analysis, visualizations, modeling, and evaluation

Dataset: Data used for the analysis
